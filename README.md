# Rainy Day LLM Stories

An ongoing, AI-driven story experience — a Perchance-style RPG where an LLM runs the narrative and I'm the player.

## What It Is

A personal project for running long-form, interactive stories powered by local LLMs (Ollama). Built for myself, not (yet) for release.
